📊 Data Flow

  1. User accesses the Function URL → Browser sends HTTP GET request
  2. Lambda function executes → Python handler processes request
  3. Weather API called → Fetches Houston weather data
  4. HTML generated → Dynamic page with weather + current time
  5. Response sent → Browser displays the dashboard
  6. User clicks service → JavaScript sends POST request
  7. Selection processed → Lambda returns confirmation
